# خلاصهٔ ارتقای NetBox

۱. پیش از هر تغییر، از پایگاه داده، پیکربندی و فایل‌های محلی نسخهٔ پشتیبان تهیه کنید و امکان بازیابی را بررسی کنید.

۲. [یادداشت‌های انتشار](https://github.com/netbox-community/netbox/releases) و [جدول سازگاری وابستگی‌ها](upgrading.md#version-history) را برای نسخهٔ مقصد بخوانید. در صورت نیاز، پیش از ارتقای NetBox نسخهٔ Python، PostgreSQL، Redis و افزونه‌ها را با نسخهٔ مقصد هماهنگ کنید. مجوزهای پایگاه داده را هم بررسی کنید.

۳. روش ارتقا را مطابق روش نصب فعلی انتخاب کنید.

- **آرشیو انتشار:** انتشار پایدار مقصد را در پوشهٔ جداگانه استخراج کنید. پیکربندی محلی، وابستگی‌های اختیاری، فایل‌های رسانه و اسکریپت‌های لازم را مطابق راهنمای کامل انتقال دهید و پیوند `/opt/netbox` را به پوشهٔ نسخهٔ جدید تغییر دهید.
- **Git:** در مخزن نصب‌شده تگ‌ها را دریافت و تگ پایدار موردنظر را انتخاب کنید.
- **بستهٔ Python:** این روش در NetBox 4.7 آزمایشی است. ابتدا سرویس‌ها را متوقف کنید، بسته و وابستگی‌های محلی را در محیط مجازی ارتقا دهید، وظایف ارتقا را با دستور `netbox upgrade --no-input` انجام دهید و پیکربندی سرویس‌ها را پیش از راه‌اندازی بررسی کنید. [مراحل ارتقای نصب بستهٔ Python](upgrading.md#upgrade-a-python-package-installation-experimental)

۴. در نصب آرشیوی یا Git، پس از آماده شدن فایل‌ها و پیکربندی، اسکریپت ارتقا را اجرا کنید.

```bash
cd /opt/netbox
sudo ./upgrade.sh
```

۵. پس از اجرای موفق اسکریپت، سرویس‌های وب و پس‌زمینه را راه‌اندازی مجدد کنید و وضعیتشان را ببینید.

```bash
sudo systemctl restart netbox netbox-rq
systemctl status netbox netbox-rq
```

سپس ورود به برنامه، نمایش داده‌ها و اجرای کارهای پس‌زمینه را بررسی کنید. برای فرمان‌های هر روش، مسیرهای نصب سفارشی و ملاحظات مربوط به مجوزها، [راهنمای کامل ارتقا](upgrading.md) را بخوانید.

## نصب خودکار انتشارهای فورک با systemd

این روش برای نصب Git روی Ubuntu با مسیر `/opt/netbox` و سرویس‌های `netbox` و `netbox-rq` است. هنگام نصب، نشانی مخزن را روی `https://github.com/aa70027/netbox.git` قرار دهید. فایل‌های برنامه و اسکریپت ارتقا باید تحت کنترل مدیر سرور باشند. پیش از فعال کردن زمان‌بندی، پشتیبان‌گیری و بازیابی پایگاه داده و فایل‌های محلی را آماده کنید.

پس از نصب NetBox، برای فعال کردن ارتقای زمان‌بندی‌شده فرمان‌های زیر را اجرا کنید. زمان‌بندی هر روز حدود ساعت ۰۳:۰۰ به وقت سرور اجرا می‌شود.

```bash
sudo install -m 644 /opt/netbox/contrib/netbox-fork-update.service /etc/systemd/system/
sudo install -m 644 /opt/netbox/contrib/netbox-fork-update.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now netbox-fork-update.timer
```

به‌روزرسان فقط [انتشار پایدار فورک](https://github.com/aa70027/netbox/releases) را بررسی می‌کند. انتشار باید با تگی مانند `v4.7.6` روی کامیتی منتشر شود که ادامهٔ تاریخچهٔ نسخهٔ نصب‌شده باشد. مقدار نسخه در `netbox/release.yaml` باید با تگ هماهنگ باشد. وقتی نسخهٔ جدیدتری پیدا شود، سرویس‌ها برای اجرای اسکریپت ارتقا موقتاً متوقف می‌شوند و بعد از موفقیت دوباره راه می‌افتند.

برای مشاهدهٔ زمان اجرای بعدی و لاگ سرویس از این فرمان‌ها استفاده کنید.

```bash
systemctl list-timers netbox-fork-update.timer
sudo journalctl -u netbox-fork-update.service
```

اگر ارتقا در میانهٔ کار متوقف شود، اجرای بعدی تا بررسی دستی متوقف می‌ماند. ابتدا وضعیت سرویس، کد و مهاجرت‌های پایگاه داده را بررسی و رفع کنید. پس از بازیابی موفق، نشانگر `/var/lib/netbox-fork-updater/upgrade-in-progress` را بردارید تا زمان‌بندی دوباره بتواند ارتقا را انجام دهد.
